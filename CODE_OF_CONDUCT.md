# Code of Conduct

## Our Commitment

We are committed to providing a welcoming, respectful and inclusive environment for everyone participating in this project.

Contributors, users and maintainers are expected to work together professionally and respectfully, regardless of experience, background or skill level.

Our goal is to build a friendly community that encourages learning, collaboration and constructive discussion.

---

## Expected Behaviour

Examples of positive behaviour include:

- Being respectful and considerate.
- Being patient with new contributors.
- Providing constructive feedback.
- Respecting different viewpoints and experiences.
- Accepting constructive criticism gracefully.
- Focusing on what is best for the project and its users.
- Helping create a welcoming environment.

---

## Unacceptable Behaviour

The following behaviour is not acceptable:

- Harassment or discrimination of any kind.
- Personal attacks or insults.
- Offensive or abusive language.
- Trolling or deliberately disruptive behaviour.
- Publishing private information without permission.
- Intimidation or threats.
- Any conduct that would reasonably be considered inappropriate in a professional environment.

---

## Project Philosophy

Masjid Display is intended to be a practical open-source project that benefits mosques, charities and community organisations.

Discussions should remain constructive and focused on improving the project.

Healthy technical disagreement is encouraged, but personal conflict is not.

---

## Reporting Issues

If you experience or witness behaviour that violates this Code of Conduct, please contact the project maintainer.

Reports will be reviewed fairly and handled as confidentially as reasonably possible.

---

## Enforcement

Project maintainers are responsible for clarifying and enforcing this Code of Conduct.

They may remove, edit or reject comments, commits, pull requests or other contributions that violate these guidelines.

Repeated or serious violations may result in temporary or permanent removal from the project.

---

## Scope

This Code of Conduct applies to:

- GitHub Issues
- Pull Requests
- Discussions
- Project documentation
- Community interactions related to this project
