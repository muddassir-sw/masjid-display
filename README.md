# Masjid Display

Masjid Display is an open-source Raspberry Pi kiosk platform for mosques.

It provides a reliable digital display for:

- Prayer times
- Announcements
- Notices
- Events
- Donations
- Digital signage

## Features

- Raspberry Pi OS
- Chromium Kiosk Mode
- Automatic startup
- Health monitoring
- Auto browser restart
- Portrait & landscape support
- Remote management (SSH/Tailscale)
- Configurable display URL
